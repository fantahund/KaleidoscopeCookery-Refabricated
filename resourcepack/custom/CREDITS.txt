Changes
-------
* Models converted to the Minecraft 26.3 format: NeoForge/Fabric-only fields (render_type, loader) removed,
  "neoforge:separate_transforms" resolved into item model definitions with select on display_context,
  item overrides converted into range_dispatch definitions on custom_model_data.
* Item model definitions (assets/<namespace>/items/) added for all models.
* Models that use textures from both the item and block atlas redirected to copies of the block textures
  under textures/item/_block/.
* Atlas entries added for additional texture folders.
* German translations and additional texts for the server plugin added.
* Own models rebuilt from the original textures and the mod's entity model code (e.g. straw hat as a head item,
  millstone, trash can, scarecrow, cold cut ham slices per bite stage); the scarecrow entity texture is copied
  to textures/block/scarecrow_entity.png.
* Own pixel art for the cookbook item; cookbook images rendered from the item models and cut from the mod's
  JEI backgrounds.
